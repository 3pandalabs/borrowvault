# ShareVault

Borrow, lend and share skills with verified neighbours in your gated society. Every handover is backed by photo proof from both sides, and payments run over UPI.

**ShareVault | by 3PandaLabs**

| Folder | What |
|---|---|
| `api/` | Fastify + Drizzle + Temporal backend. Contract: [`api/ROUTES.md`](api/ROUTES.md) |
| `web/` | Next.js on Cloudflare Workers: landing page, resident web, society-admin console |
| `app/` | Expo app for residents, with camera-only handover/return inspections |
| `infra/` | Runbooks + the [production blueprint](infra/blueprint.md) |

Status: Phase 1 build in progress (2026-10-30), not yet deployed.
